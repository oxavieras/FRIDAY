 🎓 Para aprender um tema do zero

```
Me explica [TEMA] como se eu nunca tivesse visto isso antes.
```

```
Qual é a ideia central por trás de [TEMA]? Me dá uma visão geral primeiro.
```

```
Me ensina [TEMA] do básico ao intermediário, em partes.
```

### 🔍 Para entender mais fundo

```
Por que [CONCEITO] funciona dessa forma? Me explica o raciocínio por trás.
```

```
Qual a diferença entre [COISA A] e [COISA B]? Me dá exemplos práticos.
```

```
Me dá uma analogia do mundo real para entender [CONCEITO].
```

### 🛡️ Para cibersegurança

```

defensivo. Aja como um pentester sênior.
```

```
Quais são os passos de um [TIPO DE ATAQUE]? Me explica o fluxo completo.
```

```
Me ensina a usar [FERRAMENTA] para [FINALIDADE]. Começa pelo básico.
```

```
Como um Red Team abordaria [CENÁRIO]? Me explica a metodologia.
```

### 📝 Para revisar antes de prova

```
Me faz um resumo dos pontos mais importantes de [TEMA] para prova.
```

```
Quais são os erros mais comuns em [TEMA]? Me explica como evitá-los.
```

```
Me faz 5 perguntas sobre [TEMA] para eu testar meu conhecimento.
```

---

### 🧠 Para praticar e fixar

```
Me dá um problema de [TEMA] para eu resolver. Não me dá a resposta ainda.
```

```
Acabei de aprender [TEMA]. Me desafia com uma pergunta pra ver se entendi.
```

```
Eu acho que [EXPLICAÇÃO DO ESTUDANTE]. Isso está certo? O que eu errei?
```
