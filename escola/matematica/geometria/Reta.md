### Equação Geral

Toda reta pode ser escrita na forma:

$$ax+by+c=0$$

onde a, b e c são constantes. Simples de identificar, mas nem sempre fácil de interpretar — por isso existe a forma reduzida.

$$y=mx+n$$

Essa aqui é mais intuitiva:

- **m** é o **coeficiente angular** — ele diz a _inclinação_ da reta
- **n** é o **coeficiente linear** — é onde a reta _corta o eixo y_

**O que o coeficiente angular significa na prática?**

Pensa assim: se m = 2, pra cada 1 passo que você dá pra direita no eixo x, a reta sobe 2 no eixo y. Se m for negativo, ela desce. Se m = 0, a reta é horizontal.

### Posição relativa entre duas retas

Dadas duas retas com coeficientes angulares m₁ e m₂:

| Situação        | Condição                     |
| --------------- | ---------------------------- |
| Paralelas       | m₁ = m₂ (e retas diferentes) |
| Perpendiculares | m₁ · m₂ = -1                 |
| Concorrentes    | m₁ ≠ m₂                      |
### Distância de um ponto a uma reta

Dado o ponto P = (x₀, y₀) e a reta ax + by + c = 0:

$$d = \frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}​$$
