### O que é uma função?
Pensa assim: imagina uma **máquina**. Você joga um número nela, ela processa, e te devolve outro número. Isso é uma função.

Por exemplo: uma máquina que **dobra qualquer número** que você coloca.

Coloca 3 → sai 6. Coloca 5 → sai 10. Coloca -2 → sai -4.

Essa "regra de processamento" (dobrar o número) é exatamente o que a função define.
### A linguagem matemática

Quando os matemáticos escrevem isso formalmente, usam a notação:

> **f(x) = 2x**

Lê-se: _"f de x é igual a 2x"_. Traduzindo: "a função f recebe um número x e devolve o dobro dele."

O **x** é o valor que você coloca (chamado de _variável independente_). O que sai — no caso, 2x — é o resultado (chamado de _variável dependente_, porque depende do x).

### [[Domínio, contradomínio e imagem]]
Aqui tem três conceitos que sempre aparecem juntos, e vale entender cada um:

O **domínio** é o conjunto de valores que você _pode_ colocar na função — os valores permitidos de entrada. O **contradomínio** é o conjunto de valores que a função _poderia_ em teoria devolver. Já a **imagem** é o conjunto de valores que ela _realmente_ devolve.

A diferença entre contradomínio e imagem parece sutil, mas faz sentido com um exemplo: se sua função é f(x) = x², e o domínio são os reais, o contradomínio pode ser declarado como todos os reais — mas a imagem real são só os números **maiores ou iguais a zero**, já que quadrado nunca é negativo.
### Injetora, Sobrejetora e Bijetora

Essas três dizem respeito à **relação entre domínio e imagem**.

Uma função é **injetora** quando entradas diferentes sempre geram saídas diferentes — ou seja, nunca dois x distintos produzem o mesmo resultado. f(x) = 2x é injetora: não tem como dois números diferentes, ao serem dobrados, darem o mesmo resultado.

Uma função é **sobrejetora** quando a imagem é igual ao contradomínio — ou seja, a função "cobre" todos os valores possíveis de saída. Todo elemento do contradomínio é atingido por pelo menos um x.

Uma função é **bijetora** quando ela é **injetora E sobrejetora ao mesmo tempo** — cada saída é atingida por exatamente um x, sem sobras nem buracos. Essa é a função mais "comportada" que existe.

Ou seja, uma função afim pode ser injetora, uma quadrática pode não ser, uma exponencial é sempre injetora... a classificação se aplica _por cima_ da forma da função.
