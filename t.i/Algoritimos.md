Um algoritmo é simplesmente **a sequência de passos** que você descreveu acima. Toda receita de bolo é um algoritmo. Todo fluxograma de atendimento de call center é um algoritmo.

Na prática, algoritmos têm três propriedades obrigatórias:

**Finitude** — ele precisa terminar algum dia. Um algoritmo que roda para sempre é um bug, não um algoritmo.

**Determinismo** — dados os mesmos dados de entrada, ele sempre produz a mesma saída. Se você passa `2 + 2`, sempre sai `4`.

**Efetividade** — cada passo precisa ser executável de verdade, sem magia ou ambiguidade.
